# 3D model sources and licenses

The simulator loads local, browser-optimized GLB assets. Original attribution metadata is retained in GLB `asset.extras` whenever the source file provided it.

- `yacht-sailboat-pbr.glb` — [“Catamaran”](https://sketchfab.com/3d-models/catamaran-935e9e6e370447328a706b3f59dd5329) by vtillettdive, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Adaptation: the source scene/water planes were removed, geometry was simplified from 371,675 to 162,913 triangles, and vertex data was quantized. The finished asset retains the twin hulls, mast, curved mainsail, boom, rigging, cockpit, helm and canopy.
- `shark-animated.glb` — `shark.glb` from the [BabylonJS Meshes Library](https://github.com/BabylonJS/MeshesLibrary), covered by that library's default [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) terms. The 51,199-triangle rig includes authored `swimming`, `circling`, and `bite` clips. Adaptation: textures resized to 1K WebP and geometry/animation data quantized.
- `whale-animated.glb` — [“Blue Whale - Textured”](https://sketchfab.com/3d-models/blue-whale-textured-d24d19021c724c3a9134eebcb76b0e0f) by Bohdan Lvov, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Includes the authored `Swimming` clip. Adaptation: WebP textures and quantized geometry/animation data.
- `tropical-fish-school.glb` — [“Animated Swimming Tropical Fish School Loop”](https://sketchfab.com/3d-models/animated-swimming-tropical-fish-school-loop-62ccf83b35c744d7b5ffb7be80d4ea99) by LasquetiSpice, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The asset contains four textured species sharing an authored 41-second animation. Adaptation: 512px WebP textures and quantized geometry/animation data.
- `seagull-animated.glb` — [“Flying Seagull”](https://sketchfab.com/3d-models/flying-seagull-07dde3ea7d9048588d3c4edfd37ac20d) by The lighthouse keeper / geminga, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Includes authored `flap`, `planer`, and `planer 2` clips. This optimized adaptation remains CC BY-SA 4.0.
- `dolphin-animated.glb` — [“Dolphin Animated”](https://sketchfab.com/3d-models/dolphin-animated-1049ca2426d74280831ef3bf9f2dbc57) by Akshat / shooter24994, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The smooth 3,728-triangle rig contains separate body, belly, mouth and eye materials plus a three-second authored swim cycle.
- `palm-trees-quaternius.glb` — [“Palm Trees”](https://poly.pizza/m/VYslw9DEi6) by Quaternius, Public Domain [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Five variants; wind motion is applied at runtime.
- `yacht-quaternius.glb` — legacy, unused fallback [“Sail Ship”](https://www.get3dmodels.com/vehicles/sail-ship-low-poly/) by Quaternius, Public Domain [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
