# Кампания «Аквилон»: живое ТЗ

Здесь лежит рабочая версия сюжетной кампании: из открытого мира с парусной яхтой получается приключение с сюжетом, союзниками, секторами и боями. Документ меняется вместе с игрой. Когда приходят новые наброски, правится сначала он, затем данные в коде.

| Раздел | О чём | Где это в игре |
| --- | --- | --- |
| [story.md](story.md) | Сюжет, завязка, акты, развязки | `src/simulator/story/content/chapters.ts` |
| [world.md](world.md) | Карта архипелага и пять секторов | `src/simulator/story/content/sectors.ts`, `locations.ts` |
| [characters.md](characters.md) | Герой, союзники, противники, фракции | `src/simulator/story/content/characters.ts` |
| [campaign.md](campaign.md) | Главы и миссии, шаг за шагом | `src/simulator/story/content/missions/*.ts` |
| [gameplay.md](gameplay.md) | Заметность, бой, повреждения, сальваж, экономика, прокачка | `src/simulator/story/*`, `src/simulator/combat/*` |
| [open-questions.md](open-questions.md) | Противоречия в набросках и решения, которые нужно принять | — |

Карта [map.svg](map.svg) рисуется скриптом `npm run campaign:map` из тех же данных, по которым игра определяет сектора. Поэтому на рисунке всегда та карта, которая в игре.

## Принципы, которые не меняются от правки к правке

1. **Никакого обязательного стелса.** Любую миссию можно пройти в открытом бою. Тихий подход (под парусом, ночью, в тумане) даёт преимущество: первый выстрел за вами, трофеи достаются целыми, подкрепления не приходят. Но обнаружение никогда не означает мгновенный провал.
2. **Карта как у настоящего архипелага.** Сектора не вложены друг в друга кольцами. Это соседние районы с неровными границами по проливам: рифовый пояс на юго-западе, мангровый север, засушливый атолл на юго-востоке, клин открытой воды с запада и кальдера там, куда этот клин упирается.
3. **Парус — главное оружие героя.** «Аквилон» обучен на шум винтов и тепло дизелей, поэтому парусник для него почти невидим. Это причина, по которой герой вообще может воевать, а не правило «не шуми, иначе проиграешь».
4. **Море и суша чередуются.** Яхта — дом, транспорт и боевая платформа. Высадки на острова ведут к узлам, лагерям и тайникам.
5. **Аккуратная работа выгоднее грубой силы.** Дрон, ослеплённый выстрелом в сенсор, стоит впятеро дороже взорванного.

## Как вносить правки ТЗ

Данные кампании отделены от движка. Миссия описана как список шагов: «доплыть», «поговорить», «подобрать», «вывести из строя», «починить». Чтобы поменять сюжет, обычно достаточно поправить данные. Код трогать нужно только тогда, когда появляется новый вид шага или новый противник.

- **Переименовать, переписать реплики, переставить шаги** — правка файлов в `content/`.
- **Удалить или добавить миссию** — правка `content/missions/` и поля `requires` у соседних миссий. Старые сохранения не ломаются: неизвестные миссии и шаги при загрузке отбрасываются, и игрок продолжает с ближайшего существующего шага.
- **Подвинуть границы секторов** — правка ломаных в `content/sectors.ts`. Границы между соседями общие, поэтому щелей и наложений не бывает.
- **Проверка** — `npm test` прогоняет `tests/unit/campaign-content.test.ts`. Тест проверяет все ссылки (персонажи, места, миссии), достижимость каждой миссии, отсутствие дыр между секторами, попадание мест в свои сектора и наличие текста на обоих языках.
